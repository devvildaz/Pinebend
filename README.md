# Pinebend

Pinebend is a Windows arcade rally combat prototype made with Unity.

## Open the project

- Unity Editor: **6000.6.8f1**
- Normal entry scene: `Assets/Pinebend/MainMenu.unity`
- Main race scene: `Assets/Pinebend/Pinebend.unity`

Open the project root in Unity Hub. Keep Unity `.meta` files alongside their assets; they contain the asset identifiers used by scenes and other project files.

## Version control

This repository tracks the Unity source project, packages, project settings, tools, and documentation. Unity-generated caches, local editor state, and player build output are ignored. Use focused commits and short-lived branches for changes. Unity scene and asset YAML uses Unity Smart Merge when the local Git merge driver is configured.
